# Lumière & Ombre

Pages légales statiques de l’application iPhone **Lumière & Ombre** (interprétation Belline).

| Fichier | Contenu |
| --- | --- |
| `index.html` | Accueil, liens et contact |
| `confidentialite.html` | Politique de confidentialité |
| `conditions.html` | Conditions générales d’utilisation |
| `avertissement.txt` | Avertissement (divertissement, pas de prédiction) |

Le site est publié par le Blueprint Render `render.yaml` : site statique gratuit `lumiere-ombre`, en-tête `X-Frame-Options: DENY`.
